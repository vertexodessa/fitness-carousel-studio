Privacy Policy

Last updated: 2026-09-07

1. Scope

This policy describes how Fitness Carousel Studio ("the Tool") handles data. The Tool is a personal tool operated by its owner for the owner's own TikTok account. It has no other users.

2. Data the Tool accesses

After the account owner authorizes the Tool via TikTok Login Kit, the Tool may access:

  • Basic profile information of the authorized account (display name, avatar, open id) via the scope user.info.basic.
  • The list of the authorized account's own videos and their public statistics (views, likes, comments, shares) via the scope video.list.
  • The ability to upload photo carousel drafts to the authorized account via the scope video.upload.

3. How data is stored

OAuth access and refresh tokens and the statistics of the owner's own posts are stored only on the owner's own computer, in local files. No data is sent to any third party other than TikTok's own APIs and the AI model provider used to draft content. Statistics are used solely to inform future drafts for the same account.

4. Data sharing

The Tool does not sell, rent, or share TikTok user data with anyone.

5. Data retention and deletion

All stored data can be deleted at any time by removing the local files. Revoking the Tool's access in the TikTok app (Settings, Security, Manage app permissions) invalidates the stored tokens.

6. Contact

Questions about this policy can be sent to the operator through the contact address shown on the GitHub repository hosting this page.
